Frequently asked questions

Common questions about how the Lumina demo platform is structured.

Is Lumina a real investment platform?

This version is designed as a fictional/demo web platform for UI, backend, dashboard, referral, and admin-panel learning.

How are plans activated?

A user submits payment information through the payment page. The request appears in the protected admin panel, where an admin can approve or reject it.

How do referrals affect tasks?

Each registered referral increases the user's own task reward bonus by 10%. For example, 3 referrals means a +30% task reward multiplier.

What controls the AI simulator cooldown?

The selected plan controls the number of simulator attempts available every four hours: Starter gets 1, Pro gets 2, Elite gets 3, and Legend gets 4.
